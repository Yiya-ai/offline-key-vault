算法与格式

类别支持范围
生成RSA 2048 / 3072 / 4096；ECDSA P-256 / P-384 / P-521 / secp256k1；Ed25519 / Ed448；X25519 / X448；SM2；OpenPGP RSA-3072。
密钥转换PEM、DER、无头尾 Base64 DER、PKCS#1、SEC1、OpenSSH、JWK、PPK v2/v3、OpenPGP ASCII / 二进制、X25519 raw。
证书与容器PKCS#12 / PFX、JKS 条目、X.509 证书 / 证书集合、SSH 证书和 P7B 导出。保留已读取的证书附件；不签发证书，不在线验证信任链或吊销状态。
旧格式在资源限制内导入传统 PEM 加密头、PBES1、3DES、RC2、scrypt。导出时优先采用加密 PKCS#8。
不属于网页功能密钥库、持久分类管理、库密码找回和自毁、任意默认磁盘路径、PKCS#11 本地驱动。硬件令牌请使用桌面版；网页不会上传驱动或设备私钥。

算法与格式不能任意组合。每次输入最多 128 KiB；拒绝未知算法、DSA、RSA-1024 私钥、多私钥 PFX、OpenPGP v5/v6 以及超限 KDF。JKS 可选择条目分别导出。证书签名正确不等于可信。

SM2 的 PFX 支持限于不带证书的单密钥容器。JKS 和 PPK v2 的口令保护较弱，优先选择加密 PKCS#8 或 PPK v3。
