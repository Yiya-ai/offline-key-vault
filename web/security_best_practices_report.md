# 浏览器版安全与隐私审查 / Browser security review

日期：2026-11-03。范围：本地静态浏览器版本、复用的 Python 密钥解析器、
WASM/JavaScript 依赖、构建与 GitHub Pages 工作流。测试只使用临时生成的合成密钥。
未读取用户密钥库或真实私钥，未上传项目或密钥，未发布到公网。

## 结论

发现并修复了依赖检查遗漏、发布目录校验缺口、异步操作和会话清空竞态、
私钥/密码显示状态遗留、样式请求未完全封锁及容器 MAC 参数预检不足。
没有在已审代码和所测流程中发现密钥上传接口、遥测或持久化密钥的代码路径。

**后续修复已解除本报告发现的依赖阻断项。** 从官方源码编译了 cryptography 50.0.2
与 OpenSSL 3.6.5，浏览器实际版本、格式回归及 15 包通告门禁均通过；未添加忽略列表。
旧版包改名并重算测试资源清单时也被启动检查拒绝。页面已移除对应的未修复警示。
本次未在远端运行部署工作流，也没有公网发布。
本报告不是独立审计，也不保证不存在未发现问题。

下文源码位置按本次修改后的文件行号记录；路径均为仓库相对路径。

## 高优先级

### 01 — Python/WASM 依赖不在原 npm 门禁范围内（已修复）

- 位置：`web/dependencies.lock.json:40`、`:82`；`web/audit_dependencies.py:26`；
  `.github/workflows/web-pages.yml:30`。
- 证据：原锁定 pyasn1 0.6.3；OSV 查询命中多条解析拒绝服务通告。
  [pyasn1 官方通告](https://github.com/pyasn1/pyasn1/security/advisories/GHSA-2qm8-x737-gmw5)
  将构造 BIT STRING 的累积计算问题标为高危，修复版为 0.6.5。
  输入大小限制不能替代解析器修复。
- 已修复：升级至官方 pyasn1 0.6.5，锁定下载 SHA-256；重建后查询不再命中该包。
  增加全部 15 个 Python 依赖的公开通告检查，任何通告、查询失败、分页或残缺响应
  都阻断发布。npm 检查也覆盖低风险以上通告。查询只发送公开包名和版本。
- 首次审查：官方 Pyodide 314.0.7 对应的 cryptography 为 47.0.0，WASM 二进制含
  OpenSSL 3.6.2 版本标识。现有兼容官方 WASM 运行包不能用原生 Windows/Linux wheel 替换。
  OSV 返回 7 个标识，包含重复的 PYSEC/GHSA 对应记录，不应误称为 7 个独立漏洞。

### 02 — 发布检查放过许可证目录中的额外文件（已修复）

- 位置：`web/build_web.py:130`、`web/verify_build.py:11`、`:24`、`:28`。
- 影响：如果开发者意外将敏感文件放入发布目录的 `licenses/`，旧检查仍通过，

  清单不是数字签名，无法对抗能同时修改源码、检查器和托管内容的人。

## 中优先级

### 03 — PFX MAC 未限定算法，MAC 成本未计入总预算（已加固）

- 位置：`keyvault/import_guard.py:52`、`:55`、`:62`。
- 证据：旧预检仅在 MAC 存在时检查迭代数，未限制 MAC 算法/摘要/盐，也未累计 MAC 成本。
  上游 [OpenSSL 通告 CVE-2026-34181](https://openssl-library.org/news/secadv/20260609.txt)
  涉及 PBMAC1 过短 HMAC 密钥接受问题。该通告评级为低；本工具不把 PFX 密码当成用户身份认证，
  不能夸大为已复现账号认证绕过。本次未制作成功伪造 MAC 的攻击样本。
- 修复：原生解析前只接受限定 SHA MAC、准确摘要长度、1–1024 字节盐和受限迭代数；
  拒绝 PBMAC1、无 MAC 及非空异常算法参数；MAC 计入累计派生成本。
- 验证：9 项原生回归，含正常容器、7 类异常参数及累计预算；浏览器也拒绝合成的
  PBMAC1/无 MAC/坏摘要/坏盐/超限迭代输入。传统 SHA-1 + 3DES PFX 仍可导入。
- 兼容变化：部分之前接受的无 MAC、PBMAC1 或累计成本超限容器现在会拒绝。
  该入口防护继续保留；后续已另行完成 OpenSSL 3.6.5 升级。

### 04 — 文件读取期间未完整锁定任务，旧结果可遗留（已修复）

- 位置：`web/src/app.js:23`、`:117`、`:177`、`:218`；`web/src/kernel.py:118`。
- 证据：旧版只根据 Worker RPC 是否在途禁用按钮，`File.arrayBuffer()` 的异步等待
  不属于 RPC；参数可能在等待期间变化；进入 Worker 前的文件错误会保留之前的结果。
- 影响：用户可能对错误的旧密钥执行导出，或使导出名称与实际内容不对应。
- 修复：完整任务持锁，锁定参数和导出名；读取新输入前清除旧结果与 Worker 中的旧密钥；
  会话代号使清空后的旧异步结果失效；失败时清理口令。
- 验证：人为延迟合成文件读取，检查控件锁定、旧密钥已丢弃；清空后再放行读取，
  旧结果不能恢复。无效输入也不会恢复旧密钥，错误不回显输入或口令。

### 05 — 超时检查和明文显示状态存在遗留窗口（已修复）

- 位置：`web/src/app.js:34`、`:41`、`:145`、`:251`。
- 证据：旧版依赖定时器检查空闲，同时输入事件先刷新活动时间；后台挂起再恢复时，
  首次活动可能延长过期会话。已显示私钥/密码不会在失焦时自动隐藏。
- 修复：活动之前先检查时钟与单调计时；恢复可见、获得焦点时检查；失焦/切换工具
  隐藏明文；显示状态代号阻止迟到的私钥预览覆盖隐藏操作。
- 验证：不执行计时回调而将时间推进超过五分钟，首次活动触发清空；延迟私钥结果在
  隐藏后返回仍不可见；离线清空、刷新和已有超时回归均通过。
- 限制：浏览器冻结时无法保证准点执行 JS；恢复后先清理，不承诺物理擦除内存。

### 06 — 密码切为普通文本后未关闭拼写服务（已修复提示属性）

- 位置：`web/src/index.html:57`、`:75`、`:85`；`web/tests/browser-audit.js`。
- 证据：原密码栏没有明确的 `spellcheck="false"`；小眼睛将其变为普通文本。
  浏览器增强拼写服务可能将内容交给第三方，且不属于站点 fetch 的 CSP 控制范围。
  [MDN 的隐私说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/spellcheck)
  明确提示敏感输入应关闭拼写检查。
- 修复：所有密码栏和密钥文本栏明确禁用拼写检查、自动纠正和自动大写；预览禁用自动填充。
- 验证：浏览器检查全部密码栏的属性；未使用真实口令，也未启用云拼写发送实验。
  浏览器/扩展/输入法仍需可信，HTML 属性不能强制约束恶意扩展。

## 低优先级 / 防御加固

### 07 — “网络关闭”后仍允许同站样式请求（已修复）

- 位置：`web/src/app.js:292`。
- 复现：就绪后注入本地拦截的空样式表，原 `style-src 'self'` 仍准许请求。
  未发现用户输入可注入该标签的路径，也未复现密钥外传，不应称为已证实的窃取漏洞。
- 修复：资源加载完毕后叠加 `style-src 'none'`；现有样式继续使用。
- 验证：新样式请求和 fetch 均被 CSP 拒绝；页面原样式仍有效。
  正常链接跳转、浏览器更新、扩展等浏览器外部行为不受此声明保证。

### 08 — 共享站点已有 Service Worker 的信任边界不明确（已加固）

- 位置：`web/src/app.js:264`、`:265`。
- 修复：受现有 Worker 控制时不启动；控制器变化则终止会话，丢弃预载资源，不重启。
  不自动注销其他应用。仍要求可信独立 HTTPS 站点。
- 验证：使用真实 Service Worker 的隔离浏览器上下文，应用拒绝输入；点击清空
  也不能绕过。独立 iframe 测试同样拒绝输入。
- 限制：恶意 Worker/托管方若已替换了保护代码，代码内检测本身无法提供真实性保证。
  公网托管响应头和账号权限尚未测试。

## 其他检查及未复现项

- 审查 DOM 输出：使用 `textContent`、`value`、`createElement`，未发现用户输入进入
  HTML/脚本解释器的路径；合成标签名称不产生 DOM 元素。
- Worker 只接收固定命令及数据；未知操作被拒绝；Python stdout/stderr 不输出密钥。
- 密钥只在当前内存中处理；无应用 Cookie、local/session storage、IndexedDB 或文件系统挂载。
  离线生成、导出和清空成功。导出只经用户操作创建下载，撤销 Blob URL。
- 已复核私钥预览意图、未加密导出确认、错误口令、不同密钥判定、原文保留和大小限制。
- PGP 公钥根中混入私钥子包的合成测试被拒绝，没有复现该疑似泄露路径。
- 无登录服务、数据库或服务端解析接口，SQL 注入和服务端会话鉴权不适用于本静态版本。
- CSP/资源哈希不能代替代码来源认证。静态主机可以看到访问 IP/资源请求；页面不是匿名工具。
- 下载、剪贴板、系统交换区、崩溃转储及浏览器扩展仍是外部风险；不宣称可靠物理擦除。
- 此次真实浏览器为 Windows Chromium。未实测 Firefox/Safari、手机实机或线上 HTTPS 站点。
